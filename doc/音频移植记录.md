## 1. 参考基准提取(原厂 demo_DevKitBoard)

| 项 | 原厂值 | 我们对应 |
|---|---|---|
| 演示模板 | `apps/common/example/Devkitboard_test/mic_test.c`(MIC→PCM cbuf→DAC 回环) | `app/audio_demo.c`(精简版回环自检) |
| 音频平台数据 | DevKitBoard.c: dac_data(hw_channel=0x05, ch_num=4, VCM 1000ms) + adc_data(MIC1 差分, isel=2, dump 480) | board.c 同数值; **差异: pa_auto_mute=0**(xiaolu 功放 MUTE 脚未定位, 原厂 PB02) |
| 设备注册 | `{"audio", &audio_dev_ops, &audio_data}` | 同(宏控) |
| 任务表 | audio_server(16,512,64) / audio_mix(28,512,0) / audio_decoder(30,1024,64) / audio_encoder(12,384,64) | 同 4 项(宏控注入 task_info_table) |
| 库 | audio_server.a(+大量编解码库) | **仅 audio_server.a**(PCM 回环不涉及格式解码; 试链接零缺符号实锤) |
| app_config 音频宏 | CONFIG_AUDIO_MIX_ENABLE 等 | 逐字拷贝进 MINI_AUDIO_SUPPORT 门控块 |

关键结论:
- `audio_dev_ops` 就在 audio_server.a 内(不在 cpu.a), 单库即可。
- `server/audio_server.h` 的 union audio_req **无宏门控**(布局固定), 不存在
  LCD 那类结构体错位风险; CONFIG_* 音频宏只影响应用层 demo 代码。
- server 框架(server_open/request/close)与底层 audio_dac/audio_adc 符号已在
  我们现有链接集(common_lib/cpu.a), 无需新增。

## 5. AEC 回采 (V1.1.1 追加)

机制(参考 `demo_edr/bt_decode.c` 通话编码路径, audio_server.a 内 aec_enc.c 自包含):

```c
req.enc.channel_bit_map = BIT(CONFIG_PHONE_CALL_ADC_CHANNEL) | BIT(CONFIG_AEC_ADC_CHANNEL);
req.enc.aec_enable = 1;
req.enc.aec_attr   = &aec_param;   // struct aec_s_attr(server/audio_dev.h)
//   EnableBit = AEC_EN|NLP_EN|ANS_EN(AEC_MODE_ADVANCE), 16k 时 wideband=1,
//   hw_delay_offset=50, AGC_echo_look_ahead=100, AGC_echo_hold=400 ...
//   ch_data_exchange: 回采通道号 > mic 通道号时置 1(差分回采交换)
```

回采 = DAC 输出回灌 ADC 作回声参考, 通道 `CONFIG_AEC_ADC_CHANNEL=0`(AUX0,
原厂同款); **物理路由待上板确认**——若 xiaolu-R2 的 AUX0(PA0) 未内部连 DAC,
参考信号无效(AEC 不消回声但链路仍运行), 届时按原理图改通道号。

新增依赖(试链接逐个定位, 全部已入树):
| 依赖 | 来源 | 作用 |
|---|---|---|
| libaec.a / libdns.a | 原厂 liba 拷入 | AEC/DNS 算法(aec_enc.c 引用 JLSP_ns_*/SingleMicSystem_*) |
| libjlsp.a | 原厂 liba 拷入 | JLSP_fft_destroy(DNS 内部 FFT) |
| app/jl_math/*.c+h | 原厂 apps/common/jl_math 拷入 | flrfft/flrifft 浮点 FFT 原语(WOLA 滤波器组, 闭源库内没有) |
| driver/config/log_config/lib_audio_config.c | 新写 | dns_enc_enable + AUDIO_ENCODER 日志标签(链接缺符号逐个补) |
| task_info_table += echo_deal(11,1024,32) | 参考工程同款 | AEC 处理任务 |

   jl_math 未编译, flrifft 一直缺)。
