LADC 采集

寄存器、通道、adkey 实测

实例 / 基址

基址: 0x13100(段基址 + (64×grp + adr)×4, 见 WL82.h)

LADC 数字侧仅 2 寄存器；通道/增益由 ANA（0x11900，54 寄存器）配置。应用经 adc_api.h / audio enc 访问。IRQ_SARADC=24。

寄存器

偏移寄存器属性说明
0x00CONRW控制（位域未公开）
0x04RESRO转换结果
ADC/ANA 寄存器位域未在 SDK 头文件公开，请以驱动 API / ioctl 为准。
类型通道引脚
MIC 差分LADC_CH_MIC0_P_NPA2 / PA1
MIC 差分LADC_CH_MIC1_P_NPH8 / PH9
MIC 差分LADC_CH_MIC2_P_NPA4 / PA3
MIC 差分LADC_CH_MIC3_P_NPH5 / PH6
LINEINLADC_CH_AUX0~3PA0 / PH7 / PA5 / PH4

用法

adc_init();
u32 v = adc_get_value(ch);
/* 直通: ladc_mic_to_daclr() / ladc_linein_to_daclr()
 * 录音: audio_server enc sample_source="mic"/"linein" */

约束【实测】

adkey：PB01 电阻梯，10bit 空闲≈1014 / KEY1≈162 / KEY2≈0；10ms 扫描 + 中点阈值表。采样前 gpio_set_die(脚,0)。
