Flash & Security

Flash 与安全加速器

SFC XIP、SFCENC 加密、VM 布局、AES/SHA/CRC/RAND/EFUSE

基址: 0x40200(段基址 + (64×grp + adr)×4, 见 WL82.h)

SFC = SPI NOR Flash 控制器(0x40000 区, XIP 取指), SFCENC 为配套加密引擎(0x40400 区)。烧录镜像经 isd_download 打包, 运行时读写走 sfc_norflash_api.h(norflash_read/write/ioctl 擦扇区)。

SFC 寄存器

偏移寄存器属性说明
0x00CONRW接口模式(2/4 线)/时钟分频
0x04BAUDWO波特率(sfc_clk = hsb/(baud+1))
0x08CODEWO
0x0CBASE_ADRWO

Flash 布局与 VM 区

  • 单备份: NEW_FLASH_FS=YES; 双备份: BR22_TWS_DB=YES + DB_UPDATE_DATA(OTA 载荷)
  • VM 参数区: 默认 Flash 尾部(16M flash 例: 0xFF5000~0xFFD000), syscfg_read/write API
  • 预留区: BTIF(蓝牙配对)/EXIF(客户)/VM 均可在 isd_config_rule.c 配地址与 OPT(0 擦除/1 保留/2 保护)
  • SFCENC + 0x7DF1.key: 代码加密(isd_download -key), EFUSE 存用户 key

加密与杂凑加速器

模块基址说明
AES0x41200AES 硬件(IRQ 31), aes_hw.h
DCP0x41300数据协处理(图像旋转/拷贝加速)
SHA0x11400 区SHA1/256(IRQ 56), sha_hw.h【实测: hw cbc/sha demo 通过】
CRC0x13500硬件 CRC16(CRC16()/calc_crc16_with_init_val 库内调用)
RAND0x13B00硬件随机数
EFUSE0x13700熔丝(芯片 ID/加密 key), asm/efuse.h
