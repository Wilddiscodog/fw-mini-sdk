SFC 寄存器 + VM/加密 + AES/SHA 等

实例 / 基址

模块基址说明
SFC0x40200SPI NOR XIP
SFCENC0x40300加密引擎
AES0x41200IRQ 31
SHA0x11700IRQ 56
CRC0x13500CRC16
RAND0x13B00硬件随机
EFUSE0x13700熔丝

运行时 API：sfc_norflash_api.h；SFC 时钟 = HSB/(BAUD+1)。

SFC 寄存器

偏移寄存器属性说明
0x00CONRW线宽/模式；BIT31=忙（cpu.h SFC_WAIT）
0x04BAUDWO分频
0x08CODEWO
0x0CBASE_ADRWO

位域 — SFC.CON

位域名称说明
31BUSYSFC_WAIT：等 CON.BIT31 清零（cpu.h）
SFC 其余位 / SFCENC 寄存器位域未在 SDK 头文件公开，请以驱动 API / ioctl 为准。

布局与读写

  • 单备份 NEW_FLASH_FS；双备份 BR22_TWS_DB + DB_UPDATE_DATA
  • VM 默认 Flash 尾（如 0xFF5000~0xFFD000），syscfg_read/write
  • SFCENC + 0x7DF1.key：isd_download -key；EFUSE 存用户 key
norflash_read(buf, addr, len);
norflash_write(buf, addr, len);
/* ioctl 擦扇区；XIP 取指时勿擦正在执行的 bank */
