USB 双控制器

FUSB1.1 + HUSB2.0: MUSB 差异、EP RAM DMA 桥(0x16800)、EP3/4 大缓冲【实测逆向】

两个独立 USB 控制器共用 D+/D- 引脚(不可同时启动):

控制器基址规格角色
USB0 (FUSB)0x11800全速 12Mbps设备/主机(小缓冲)
USB1 (HUSB)0x12800高速 480Mbps设备/主机/OTG

【实测·重要】MUSB 兼容内核的三处 JL 差异(逆向 usb.a 得出): ① TXIS/RXIS 窗口读自动清除(写 1 清除无效); ② EP0 只有 FIFO 端口 0x16020, EP≥1 无 FIFO 端口——数据面走 RAM DMA 缓冲; ③ 无 FIFOSZ 寄存器, EP FIFO 容量硬件固定。

EP 数据面 RAM DMA【实测逆向】

EP≥1 的收发不经 FIFO 端口, 而是桥接寄存器指向的 RAM 缓冲(仅 RAM0 段):

地址名称说明
0x16800桥接配置EP DMA 总开关/映射
0x16804+4×epTXCNT(ep)发送字节计数(必须先于 TXRDY 写, 否则发 0 长度包)
0x16820+8×(ep-1)TADDR(ep)发送缓冲地址(RAM0!)
0x16824+8×(ep-1)RADDR(ep)接收缓冲地址(RAM0!)
0x16850 / 0x16854EP3/EP4 大缓冲模式TXCSR/RXCSR bit14 使能
  • EP1/2/5/6: 普通 DMA 模式, 缓冲需 64 字节对齐
  • EP3/4: 大缓冲模式, 计数打包 (dma_size<<16)|len|0x80000000, 8 字节对齐, 单次可搬 4096B
  • 主机模式(MRX): 多包聚合, Inclusive/Exclusive 分组读
  • 【实测】SDRAM 缓冲会静默丢数据——DMA 只能到 0x1C00000 RAM0 段

协议栈与实测结论

  • 官方栈(liba/lib_usb_syn.a + driver/usb): 多复合设备(CDC×n+MSC+UAC…), usb_epbuf_manager 用 lbuf 统一分发 EP 缓冲
  • fw-mini-sdk 换用 CherryUSB(port/jl82 适配上述 DMA 语义), MSC 4MB RAM 盘 + 虚拟U盘 OTA 实测通过
  • 【实测】INT 端点需置 TXCSR.H bit14(CSRH bit6), 否则 clear-halt 死循环
  • 【实测】主机 EP0 控制传输完成中断不触发, 需轮询 CSR0
