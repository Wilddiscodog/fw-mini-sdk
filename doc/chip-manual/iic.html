I²C 总线

硬件 CON0 位域 + 软 IIC 路径

实例

基址: 0x12400(段基址 + (64×grp + adr)×4, 见 WL82.h)

硬件 I²C 一组（IRQ 23）+ 软件模拟 sw_iic。固定口 4 组见 iic.h（PA7/8、PC1/2、PH0/1…）。

寄存器 + CON0 位域

偏移寄存器属性说明
0x00CON0RW启停/ACK/方向/pending（iic.h 宏）
0x04BUFRW数据
0x08BAUDWO时钟分频
0x0CCON1RW从机地址 / IO 映射相关

位域 — IIC.CON0

位域名称说明
2CFG_DONE配置完成（iic_cfg_done）
3DIR0=输出 1=输入（iic_set_output/input）
4STOP加结束位（iic_add_end_bit）
5START加起始位（iic_add_start_bit）
6NACK0=ACK 1=NACK（iic_set_ack/unack）
7ACK_IN读 ACK 状态（iic_ack_in）
12CLR_EPND清结束位 pending
13EPND结束位中断标志
14CLR_PND清普通 pending
15PND中断标志（iic_pnd）

用法

/* 硬件 */
dev_open("iic0", NULL);
iic_write_regs(...);  iic_read_regs(...);

/* 软件【实测 CST816】: board 注册 sw_iic0 → dev_open("sw_iic0")
 * 注意: 勿对同一总线嵌套 IIC_IOCTL_START 造成死锁 */

约束

  • 硬件支持从机模式（CON1 地址）
  • 【实测】触摸驱动用软 IIC 时避免重复 START ioctl
依据官方 SDK asm/uart.h·uart_dev.h·spi.h·iic.h·pwm.h 与 WL82.h；位域仅收录头文件/【实测】明确项。
