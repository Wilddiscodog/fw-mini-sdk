概述

AC7912BB 是杰理 AC791N(WL82) 系列的 AIoT SoC: 双核 pi32v2 DSP 架构, 片内集成 2.4GHz WiFi4 基带+射频、经典蓝牙/BLE 控制器、SFC SPI NOR 控制器(XIP)、SDRAM/PSRAM 控制器、双 USB 控制器(全速+高速)、摄像头 DVP 接口、JPEG 编解码、8080 并口与 RGB 屏接口、完整的音频链(DAC/LADC/IIS/PLNK/ALNK/EQ/ANC)。本手册按官方 SDK 头文件逆向整理(寄存器偏移=结构体成员序×4, 基址=(64×grp+adr)×4+段基址)。

SDK 原始路径: include_lib/driver/cpu/wl82/asm/; 寄存器结构体在 WL82.h(1330 行), 中断号在 hwi.h。

系统总线与外设地址映射

外设分三段: LSB 低速段 0x1_0000~、HSB 高速段 0x4_0000~、PORT 端口段 0x5_0000~。每个外设基址 = 段基址 + (64×grp + adr)×4。

启动与固件布局

启动入口由 isd_config.ini 决定: SFC(XIP) 模式 ENTRY=0x2000120, SDRAM 模式 ENTRY=0x4000120。uboot(0x1c02000 附近)→ app 双备份/单备份布局由 isd_download 打包; VM 参数区默认在 Flash 尾部(如 0xff5000~0xffd000)。

  • 单备份(NEW_FLASH_FS): app 连续存放, 升级经 uboot 从 SD/U 盘重写
  • 双备份(BR22_TWS_DB + DB_UPDATE_DATA): app 区双份, OTA 直接写备用 bank
  • 【实测】fw-mini-sdk 使用双备份 + U 盘/网页双通道 OTA(update.a dual_bank 链路)
