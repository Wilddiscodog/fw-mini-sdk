寄存器 + API 标志位

偏移寄存器属性说明
0x00CONRW模式/位宽/CS/时钟沿等（位域未公开，经 spi_set_*）
0x04BAUDWO波特率分频
0x08BUFRW数据 FIFO

spi.h 平台/模式标志（非 CON 硬件位）

位域名称说明
0SPI_MODE_SLAVE从机模式（spi.h）
1SPI_UPDATE_SAMPLE_SAME更新与采样同沿
2-9SPI_SCLK_*空闲电平 + 更新/采样沿组合（见 spi.h）
10SPI_UNIDIR_MODE单向仅 DO
11SPI_BIDIR_MODE双向 DO/DI
12SPI_WR_UNUSE_SEM读写不等待信号量
13SPI_SCLK_PORT_HDCLK 强驱
SPI CON 硬件 寄存器位域未在 SDK 头文件公开，请以驱动 API / ioctl 为准。

初始化与传输

dev_open("spi2", NULL);
/* ioctl: 波特率/模式/端口切换/非阻塞 */
ioctl(fd, IOCTL_SPI_SET_BIT_MODE, mode);
ioctl(fd, IOCTL_SPI_SET_PORT, 0);       /* 同组 ABC 口切换 */
ioctl(fd, IOCTL_SPI_NON_BLOCK, 1);
/* 读写: spi_read_write / dev_read/write；DMA 走 ADR/CNT */

约束

  • SPI_MAX_SIZE ≈ 2^31-1（有符号赋值限制）
  • 非阻塞发送休眠前需 IOCTL_SPI_WRITE_NON_BLOCK_FLUSH
  • SFC 专用 ioctl：IOCTL_SFC_*（见 spi.h）
依据官方 SDK asm/uart.h·uart_dev.h·spi.h·iic.h·pwm.h 与 WL82.h；位域仅收录头文件/【实测】明确项。
