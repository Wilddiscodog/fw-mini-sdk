SPI

SPI 总线 ×4

SPI0-3: 寄存器、SFC 引脚组、DMA 传输

基址: 0x11C00(段基址 + (64×grp + adr)×4, 见 WL82.h)

SPI0~3 四组(0x11C00~0x11F00 区)。SPI0 首选作 SFC NOR 引脚组(CS:PD3 CLK:PD0 D0:PD1 D1:PD2, 见 isd_config SPI=2_1_0_0); 每组 5 寄存器, 数据经 BUF FIFO 或 ADR/CNT DMA。

SPI 寄存器

偏移寄存器属性说明
0x00CONRW模式/位宽/CS/时钟沿/双向半双工等(spi.h spi_set_*)
0x04BAUDWO波特率分频
0x08BUFRW数据 FIFO
0x0CADRWODMA 地址
0x10CNTRWDMA 计数
