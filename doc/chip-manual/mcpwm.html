MCPWM

PWM 控制器

8 通道互补输出、死区、两位小数占空比

基址: 0x15000(段基址 + (64×grp + adr)×4, 见 WL82.h)

多通道 PWM 控制器(0x15000 区, 58 寄存器): 8 输出通道(PWMCH0-7_H/L 互补对)、多个 32bit 时基(timer con/cnt/prd)、死区/换向。驱动头 asm/pwm.h。

pwm 驱动(pwm.h)

struct pwm_platform_data d = {
    .pwm_ch  = PWM_TIMER2_OPCH2, .freq = 1000,
    .duty    = 50.0f,            /* 支持 0.00~100.00 两位小数(point_bit) */
    .port    = IO_PORTC_05,      /* 经 IOMAP 输出通道映射到 IO */
    .deathtime = 0,              /* 死区 0-31 个系统周期 */
};
/* ioctl: PWM_RUN/STOP/PWM_SET_FREQ/PWM_SET_DUTY/PWM_SET_DEATH_TIME... */
