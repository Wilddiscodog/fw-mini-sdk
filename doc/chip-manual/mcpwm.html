pwm.h 通道掩码（API 层）

位域名称说明
0-7PWMCH0_H..7_H高侧通道掩码（pwm.h）
10-17PWMCH0_L..7_L低侧通道掩码（偏移 PWM_CHL_OFFSET=10）
20-21PWM_TIMER2/3_OPCHTIMER2/3 PWM 输出通道
MCPWM 硬件 CON 寄存器位域未在 SDK 头文件公开，请以驱动 API / ioctl 为准。

初始化

struct pwm_platform_data d = {
    .pwm_ch = PWM_TIMER2_OPCH2, .freq = 1000,
    .duty = 50.0f, .port = IO_PORTC_05,
    .deathtime = 0,   /* 0~31 系统周期 */
};
/* ioctl: PWM_RUN/STOP / PWM_SET_FREQ / PWM_SET_DUTY / PWM_SET_DEATH_TIME */
【实测】背光可用 MCPWM/Timer-PWM 经 IOMAP；GPIO 直推仅开关。
