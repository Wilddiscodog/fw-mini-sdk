TIMER

定时器与计数器

TIMER0-5 + PCNT/GPCNT, sys_timer 框架

基址: 0x10400(段基址 + (64×grp + adr)×4, 见 WL82.h)

TIMER0~5 六组(0x10400~0x11200 区), 每组 4 寄存器(CON/CNT/PRD/…)。OS tick 用 IRQ_TICK_TMR; TIMER2/3 额外可作 PWM 输出(PWM_TIMER2_OPCH2/3)。

TIMER 寄存器

偏移寄存器属性说明
0x00CONRW使能/模式(定时·计数)/中断
0x04CNTRW当前计数值
0x08PRDRW周期(自动重装)
0x0CPWMRW
/* sys_hi_timer 框架: sys_timer_add/sys_timeout_add_to_task(任务名, ...) */

PCNT / GPCNT 计数器

基址: 0x11000(段基址 + (64×grp + adr)×4, 见 WL82.h)

基址: 0x11100(段基址 + (64×grp + adr)×4, 见 WL82.h)

外设基址寄存器说明
PCNT0x11000CON/VAL简单脉冲计数
GPCNT0x11100CON/NUM门控脉冲计数(GPCNT_PLATFORM_DATA: gpcnt_gpio/gss_clk_source(PLL 480M)/ch_source/cycle(15 档门控)【实测: periph_demo】)
