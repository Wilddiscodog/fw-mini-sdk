TIMER

定时器与计数器

TIMER0-5 + PCNT/GPCNT

实例

实例基址IRQ说明
TIMER0~30x10400 起4~7通用定时
TIMER4/5见 WL82.h62/63扩展
TICK_TMR—3OS tick

TIMER2/3 可作 PWM 输出（PWM_TIMER2_OPCH2 / PWM_TIMER3_OPCH3，pwm.h）。timer 时钟 = LSB（clock 章）。

TIMER 寄存器

偏移寄存器属性说明
0x00CONRW使能/模式/中断（位域未公开）
0x04CNTRW当前计数
0x08PRDRW周期（自动重装）
0x0CPWMRW
TIMER CON 寄存器位域未在 SDK 头文件公开，请以驱动 API / ioctl 为准。

用法

/* 系统软定时 */
sys_timer_add(priv, cb, msec);
sys_timeout_add_to_task("app_core", priv, cb, msec);
/* 硬件: 配 CON/PRD 后 request_irq(IRQ_TIMERn_IDX, …) */

PCNT / GPCNT

基址: 0x11000(段基址 + (64×grp + adr)×4, 见 WL82.h)

基址: 0x11100(段基址 + (64×grp + adr)×4, 见 WL82.h)

外设基址寄存器说明
PCNT0x11000CON/VAL脉冲计数
GPCNT0x11100CON/NUM门控计数；GPCNT_PLATFORM_DATA 配 gpio/源/门控档
