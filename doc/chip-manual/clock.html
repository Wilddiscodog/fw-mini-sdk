时钟系统

时钟树、isd 烧录、分频公式、JL_CLOCK 位域、运行时 API

时钟树总览

OSC → PLL/PLL2/PLL3 → SYS → HSB/LSB → 外设（依据 clock.h + ota-loader clock.c）

两条配置路径：① 烧录态 isd_config.ini（由 isd_config_rule.c 生成）由 uboot 上电写 PLL/分频；② 运行态 asm/clock.h 的 system_clock_set / clk_get 等。开源位定义与推算公式参考 ac791n-ota-loader/.../clock_hw.h、clock.c（gitee-repos-Other）。

分频关系（clk_early_init 推算）

时钟公式 / 来源典型值(默认 isd)

PLL 档CLK_CON2[3:0]：0=192 /1=137 /2=320 /3=480 /4=107 M；≥5→PLL2/3对应 SYS=240M 档

isd 注释写明分频系数 = 配置值+1。默认 SYS_CLK=240MHz; HSB_DIV=1; LSB_DIV=2; → HSB=120M、LSB=40M。勿把 HSB 当成与 SYS 同频。
/* ac791n-ota-loader clock.c 核心推算（摘录） */
u8 div1 = clk_div1[(JL_CLOCK->CLK_CON2 >> 4) & 3];  /* 1,3,5,7 */
u8 div2 = clk_div2[(JL_CLOCK->CLK_CON2 >> 6) & 3];  /* 1,2,4,8 */
u8 pll_div = JL_CLOCK->CLK_CON2 & 0xF;
/* pll_div→192/137/320/480/107M 后再 /div1/div2 → sys_clk */
hsb = sys / (((SYS_DIV >> 16) & 0x3) + 1);
lsb = hsb / (((SYS_DIV >> 8) & 0x7) + 1);

烧录配置（isd_config）

改 cpu/wl82/tools/isd_config_rule.c 后重新打包下载，参数进入 uboot，不是应用启动后再写一次 ini。

键含义常用取值
OSC / OSC_FREQ晶振源与频率OSC0 / 24MHz（亦见 40M 机型）
SYS_CLK系统主频目标240M（默认）；320M；超频 396M 需抬 DVDD
HSB_DIV高速总线分频码（实际÷(值+1)）1 → HSB=SYS/2
LSB_DIV低速总线分频码（实际÷(值+1)）2 → LSB=HSB/3
SDRAM_PLL3_EN1：SDRAM 用 PLL3（须 SYS=240M）并可开 USB2.0量产常 1
SDRAM_PLL3_NOUSB_EN1：PLL3 跟 SDRAM_CL，但禁用 USB2.00
SDRAM_CLSDRAM 时钟档（非 PLL3 时）0=120…3=240…11=288；上限 288M
SDRAM_DQ_DLY_TRMDQ 刷新延时档5≈240M
VDDIO / DVDD / DCDC14IO/核/DCDC 电压档超频须抬 DVDD（如 14→1.35V）
/* 默认量产片段（isd_config_rule.c） */
OSC_FREQ=24MHz;
SYS_CLK=240MHz;
HSB_DIV=1;   /* HSB = 240/(1+1) = 120M */
LSB_DIV=2;   /* LSB = 120/(2+1) = 40M */
SDRAM_PLL3_EN=1;  /* SDRAM@240M + USB2.0 可用 */
SDRAM_CL=3;

/* 超频示例（CONFIG_OVERCLOCKING_ENABLE，量产慎用） */
SYS_CLK=396MHz; HSB_DIV=1; LSB_DIV=1;
DVDD=14; DCDC14=4;  /* 抬核压 */
7913/7915 + RTC 内置电源时 SDK 会把 HSB_DIV=2、LSB_DIV=5（P33 降速）。换板核对 isd 条件编译。

JL_CLOCK 寄存器与位域

基址: 0x10000(段基址 + (64×grp + adr)×4, 见 WL82.h)

与 JL_POWER 同基址 0x10000：PWR_CON ≡ POWER->CON。成员名以 WL82.h 为准（非旧文档的 CON0 简称）。

偏移寄存器属性说明
0x00PWR_CONRW电源控制（同 JL_POWER->CON）
0x04RESERVED0RW保留
0x08SYS_DIVRWHSB/LSB（及部分 SFC）分频
0x0CCLK_CON0RW主时钟源 / RC / 时钟输出脚
0x10CLK_CON1RWUART/USB/DAC/WL 等外设时钟源
0x14CLK_CON2RW系统 PLL 档与后分频
0x18CLK_CON3RW扩展（SDK 少直接操作）

运行时配置方法

include_lib/.../asm/clock.h（fw-mini-sdk / AC79 SDK 同款应用 API）：

API作用范围/说明
clk_get(name)读缓存频率"sys"/"sdram"/"hsb"/"lsb"/"uart"/"timer"/"sd"/"spi"/"osc"
clk_set(name, clk)按名改频依赖闭源实现；改前走 critical handler
system_clock_set(clk)改系统时钟24M~396M
sdram_clock_set(clk)改 SDRAM 钟96M~244M（SDRAM_CLK_MIN=96M）
system_sdram_clock_set(sys, sdr)同时改两者同上
system_clock_set_default()恢复上电初值uboot 写入的 SYS/SDR
system_clock_set_idle()idle：SYS=24M，SDR 固定 120M低功耗
system_clock_hsb_lsb_div(h,l)临时改 HSB/LSB 分频hsb=sys/h（1~4），lsb=hsb/l（1~8）；须配对 resume
sys_clk_source_set(i)主时钟源0=BT_OSC 1=RTC 2=PLL_OSC
sys_clk_source_rc_clk_on/off切 RC 16M/250K休眠路径
clk_out_pc0 / clk_out_pa0把内部钟打到 IO调试测频
system_vdd_clock_set(i)自定义 VDD+CLOCK 档与电压表联动
/* 读频 */
printf("sys=%d hsb=%d lsb=%d sdram=%d\n",
       clk_get("sys"), clk_get("hsb"), clk_get("lsb"), clk_get("sdram"));

/* 运行时降频（注意外设波特率/定时器依赖） */
system_clock_set(SYS_CLK_120M);
/* 或临时只拉大 HSB/LSB 分频 */
int tok = system_clock_hsb_lsb_div(2, 4);  /* hsb=sys/2, lsb=hsb/4 */
/* ... 临界业务 ... */
system_clock_hsb_lsb_div_resume(tok);

/* 改频临界区：驱动注册 enter/exit */
CLOCK_CRITICAL_HANDLE_REG(uart, uart_clk_enter, uart_clk_exit);
改 SYS/HSB/LSB 后 UART 若绑 LSB 需重配波特率；uboot 常把 UART 固定 48M（CLK_CON1），与 LSB 脱钩。SFC BAUD、定时器 tick 也要复核。

外设时钟源（CLK_CON1）

  • UART：推荐 PLL48M（与波特率计算稳定）；亦可 OSC/LSB
  • USB FS（FUSB）侧选源：PLL48M / OSC / LSB
  • DAC：PLL24M / OSC / LSB
  • BT/WL：STD_48M、OSC、HSB 等（与射频库绑定，勿随意改）
  • GPCNT：可选 SRC/SFC/HSB/AUDIO/WL/USB 作计数源

为何高速 USB 要求 SYS=240M？

高速 USB（HUSB / USB2.0 HS）并不吃 CPU 的 240M，PHY 需要的是固定 480 MHz UTMI 钟。官方把「SYS=240M + SDRAM_PLL3_EN=1」绑在一起，是因为 USB PLL3 与 SDRAM 时钟共用同一套 PLL3，只能同时满足一组比例。

节点频率来源
USB PLL3（HUSB_COM_CON0[27:18]+2）480 MHzHS PHY / UTMI 基准
SDRAM（8phase，CON0.BIT11）PLL3÷2 = 240 MHzHUSB_COM_CON2[4:3]==3 时走 PLL3（clock.c）
SYS_CLK（isd 强制）240 MHz与 SDR@240 + DQ_DLY/电压档成套；非 PHY 直接输入
HSB / LSBSYS/(HSB_DIV+1) 等与 USB 无硬接线比例
/* ota-loader clock.c */
usb_pll3_clk = ((HUSB_COM_CON0 >> 18) & 0x3FF) + 2;   /* MHz 量纲 */
if (((HUSB_COM_CON2 >> 3) & 0x3) == 0x3) {            /* PLL3 → SDR */
    sdram_clk = (JL_SDR->CON0 & BIT(11))
                ? (usb_pll3_clk / 2 * 1000000) : 0;   /* 固定 ÷2 */
}
  • SDRAM_PLL3_EN=1：PLL3 锁在 USB 可用的 480M → SDR 固定 240M；isd 要求 SYS_CLK=240M，SDK 宣称可开 USB2.0
  • SDRAM_PLL3_NOUSB_EN=1：PLL3 按 SDRAM_CL 改到别的钟（120~288M 档）→ 不再保证 480M PHY → 不能用高速 USB
  • SDRAM_PLL3_EN=0：SDR 改走 PLL2÷2；高速 USB 是否单独开 PLL3 取决于 uboot/闭源库，官方推荐路径仍是 PLL3 共享方案
  • 全速 FUSB（12Mbps）走 CLK_CON1 的 48M 等源，不受 SYS=240 约束
改 system_clock_set 把 SYS 调离 240M 时，勿假定 HS USB 仍可用：PLL3/SDR 比例由 uboot 烧录态决定，运行时改 SYS 不会自动重锁 USB PHY 480M。

约束与【实测】

  • 主频/分频以 isd 烧录为准；应用 system_clock_set 会改运行值但不改 Flash 内 uboot 参数
  • 超频须同步抬 DVDD/DCDC14；量产默认关闭 CONFIG_OVERCLOCKING_ENABLE
  • soft poweroff（P33）唤醒后时钟由 uboot/SDK 恢复路径决定
  • LSB 丢失：JL_OSA->CON=0x6D + IRQ_OSA → 打印 lsb clk lost（debug.c）
  • 测频：clk_out_pa0(PLL_SYS_CLK_OUT) / clk_out_pc0(HSB_CLK_OUT) 用示波器核对
