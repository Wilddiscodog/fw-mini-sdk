时钟树

AC7912BB 时钟树(isd_config_rule.c + clock.h)

SDK 预设主频(clock.h): 320M/240M/192M/160M/120M/96M/48M/40M/24M…; SDR 最低 96M(SDRAM_CLK_MIN)。时钟/分频由 isd_config.ini 烧录进 uboot 参数(非运行时寄存器直写), 应用层用 clk_get()/clk_set() 修改。

时钟寄存器(JL_CLOCK @ 0x10000)

偏移寄存器属性说明
0x00PWR_CONRW
0x04RESERVED0RW
0x08SYS_DIVRW
0x0CCLK_CON0RW
0x10CLK_CON1RW
0x14CLK_CON2RW
0x18CLK_CON3RW

基址: 0x10000(段基址 + (64×grp + adr)×4, 见 WL82.h)

/* clock.h API */
u32 clk_get(const char *name);   /* "sys"/"sdram"/"hsb"/"lsb"/"timer" */
int clk_set(const char *name, u32 clk);

低功耗与时钟保持

  • soft poweroff(P33 域保持, 10ms 后唤醒)——net_update 复位路径用到【实测】
  • LSB 时钟丢失监控: JL_OSA->CON=0x6D + IRQ_OSA, 丢失即打印 'lsb clk lost'(debug.c)
  • 低功耗配置宏 TCFG_LOWPOWER_*(app_config.h), DVDD/VDDIO 档位由 isd_config 烧录
