UART

UART 串口 ×3

UART0-2 寄存器、环形 DMA、调试口配置(含 putbyte 反汇编还原)

基址: 0x12000(段基址 + (64×grp + adr)×4, 见 WL82.h)

UART0/1/2(0x12000/0x12400 区), 11 个寄存器/组。支持中断+环形 DMA 收(RXSADR/RXEADR/RXCNT), 发送可查寻或 DMA(TXADR/TXCNT)。波特率 BAUD 寄存器与主频相关。

偏移寄存器属性说明
0x00CON0RW控制: bit0 使能 / bit13 启动发送 / bit15 发送完成【实测】; 9bit/校验等
0x04CON1RW中断使能与标志
0x08BAUDWO波特率分频(WO)
0x0CBUFRW发送/接收数据口
0x10OTCNTRW接收超时计数
0x14TXADRRW发送 DMA 起址
0x18TXCNTWO发送 DMA 计数
0x1CRXSADRRW
0x20RXEADRRW
0x24RXCNTRW
0x28HRXCNTRO硬件接收计数(RO)

查寻收发(裸机/异常路径)

/* cpu.a 弱 putbyte 反汇编还原【实测】, UART0=0x12000 */
JL_UART_TypeDef *u = JL_UART0;
if (c == '\r') return;                  /* \r 丢弃 */
if (!(u->CON0 & BIT(0))) return;         /* 未使能静默丢弃 */
u->CON0 |= BIT(13);                      /* kick 发送 */
u->BUF = c;                              /* 写数据口 */
__asm_csync();
while ((u->CON0 & (BIT(15)|BIT(0))) == BIT(0));   /* 等 bit15=1 */
【实测】查询等待建议加有界超时(如 2 万拍), 串口时钟未就绪时 bit15 永不置位会死循环(fw-mini-sdk V0.9.1 教训)。

    .flags = UART_DEBUG,        /* 调试口 */
    .baudrate = 1000000,
UART0_PLATFORM_DATA_END();
