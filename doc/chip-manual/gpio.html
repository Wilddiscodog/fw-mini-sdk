GPIO

GPIO 与 IO 复用

PORT A~H 寄存器、IOMAP 输入输出映射、唤醒源

基址: 0x50000(段基址 + (64×grp + adr)×4, 见 WL82.h)

8 组端口(A~H), 每组 9 个寄存器, 结构完全一致(JL_PORT_FLASH_TypeDef): OUT/IN/DIR/DIE/PU/PD/HD0/HD/DIEH。SDK API 在 asm/gpio.h。

端口寄存器(每组 ×9)

偏移寄存器属性说明
0x00OUTRW输出锁存(写 0/1 控制引脚电平)
0x04INRO输入采样(只读)
0x08DIRRW方向: 0=输出 1=输入
0x0CDIERW数字输入使能(0=模拟)
0x10PURW内部上拉使能
0x14PDRW内部下拉使能
0x18HD0RW
0x1CHDRW
0x20DIEHRW高耐压数字输入使能
/* gpio.h 常用 API */
gpio_direction_output(IO_PORTA_06, 1);   /* 输出高 */
gpio_direction_input(IO_PORTB_01);
gpio_set_pull_up(IO_PORTB_01, 1);
gpio_set_die(IO_PORTB_01, 1);            /* 数字输入使能(ADC 复用时关) */

IOMAP 输出通道复用

外设输出(时钟/PWM/PLNK SCLK 等)经 JL_IOMAP(0x51007 区)路由到任意 IO:output channel(CH0_PLNK0_SCLK_OUT / CH1_UART0_TX …)由 gpio_output_channle() 映射; 输入通道由 gpio_uart_rx_input()/gpio_plnk_rx_input() 反向映射。

/* DevKitBoard 例: PLNK0 数字麦重映射 PH2=DAT, PH3=SCLK */
gpio_plnk_rx_input(IO_PORTH_02, 0, 0);
gpio_output_channle(IO_PORTH_03, CH0_PLNK0_SCLK_OUT);
JL_IOMAP->CON3 |= BIT(18);

唤醒与端口中断

  • PORT 域 WAKEUP 寄存器(0x51003 区): 睡眠唤醒源(PORT_EDGE/LEVEL)
  • port_waked_up.h: 唤醒源回查 API
  • 【实测】xiaolu-R2: PB1 兼长按复位(RESET=PB01_08_0, isd_config), PC1_Wu/PC0_Wu 等带 Wu 后缀引脚支持唤醒
