GPIO 与 IO 复用

PORT A~H 寄存器、IOMAP、唤醒

实例与基址

基址: 0x50000(段基址 + (64×grp + adr)×4, 见 WL82.h)

8 组端口 PORTA~H（PORT 段），共用 JL_PORT_FLASH_TypeDef。API：asm/gpio.h。时钟：端口属常开域，无独立门控宏。

实例基址(WL82.h)说明
PORTA0x50000常用 GPIO / 部分模拟脚
PORTB0x50040按键 / UART 等
PORTC~H见 WL82.h复用外设、唤醒脚(Wu)

端口寄存器(每组 ×9)

偏移寄存器属性说明
0x00OUTRW输出锁存
0x04INRO输入采样(RO)
0x08DIRRW方向: 0=输出 1=输入
0x0CDIERW数字输入使能(0=模拟)
0x10PURW内部上拉
0x14PDRW内部下拉
0x18HD0RW强驱动档位 0
0x1CHDRW强驱动档位
0x20DIEHRW高耐压数字输入使能
位域按「每 bit 对应一脚」操作，无独立命名位宏；用 gpio_* API 或直接掩码 PORT->DIR |= BIT(n)。

推荐初始化

/* 输出 / 输入 */
gpio_direction_output(IO_PORTA_06, 1);
gpio_direction_input(IO_PORTB_01);
gpio_set_pull_up(IO_PORTB_01, 1);
gpio_set_die(IO_PORTB_01, 1);     /* ADC 复用脚采样前关 DIE */
gpio_set_hd(IO_PORTA_06, 1);      /* 需要时开强驱 */

IOMAP 复用

外设输出经 JL_IOMAP 路由；gpio_output_channle() / gpio_uart_rx_input() / gpio_plnk_rx_input()。

gpio_plnk_rx_input(IO_PORTH_02, 0, 0);
gpio_output_channle(IO_PORTH_03, CH0_PLNK0_SCLK_OUT);
JL_IOMAP->CON3 |= BIT(18);

唤醒与约束

  • WAKEUP 寄存器(PORT 段): 边沿/电平唤醒
  • port_waked_up.h 回查唤醒源
  • 【实测】PB1 可兼长按复位(isd_config RESET=PB01_…)；带 Wu 后缀脚支持唤醒
