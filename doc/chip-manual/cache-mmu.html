Cache、MMU 与异常调试

I$/D$ way、非缓存窗口、TLB、corex2/EMU 寄存器与 DBG_MSG 对照

存储层次

CPU ↔ Cache/MMU ↔ 可缓存/非缓存窗口 ↔ PRP

核 SFR 基址 csfr_base=0x1EE0000（asm/csfr.h）。Cache 控制在 corex2；每核 EMU/ETM/中断配置在 q32DSP(n)。应用 API：asm/cache.h、asm/cpu.h（NO_CACHE_ADDR / 屏障）。

I-Cache / D-Cache

Cache way 回收为 cache_ram
  • 各 8 way，行长 CACHE_LINE_COUNT=32（cache.h）
  • 寄存器: corex2(0)->CACHE_CON / DCACHE_WAY / ICACHE_WAY
  • dcache_way_use_select(cpu_way, prp_way)：D$ way 在 CPU 与 PRP 间分配
  • dcache_cwt_set(en, start, end) 写直通窗口；dcache_cwt_buffer_sync / flush_dcache / flushinv_dcache
  • CACHE_WAIT()：等 CACHE_CON & BIT(14)（cpu.h）

位域 — CACHE.CON

位域名称说明
14CACHE_RDYCACHE_WAIT：等 CACHE_CON.BIT14（cpu.h）
/* 典型一致性（DMA 前） */
flush_dcache(buf, len);          /* 或 flushinv_dcache */
__asm_csync();                   /* 核屏障 */
/* 外设用非缓存别名时可: ptr = (void *)NO_CACHE_ADDR(buf); */

非缓存地址窗口

NO_CACHE_ADDR(addr)：若 addr ≥ 0x4000000 则 addr + 0x4000000（落到 0x8000000 段非缓存视图）；CPU_ADDR 反向。用于 CPU 与 DMA 共享缓冲时绕过 D$。另配 __asm_csync / __asm_ssync 屏障。【实测】USB/EMI 路径对一致性敏感，勿混用脏 cache 行与 DMA。

#define NO_CACHE_ADDR(addr) \
    (u32)(((u32)(addr) >= 0x4000000) ? ((u32)(addr)+0x4000000) : (u32)(addr))

MMU / TLB

  • 可选：CONFIG_MMU_ENABLE（sdk_ld_sfc.c / sdk_ld_sdram.c）
  • 使能时 RAM0 起址放置 2 张 TLB（CPU0/CPU1 各 0x2000，共 16KB）
  • CPU0/CPU1 与 PRP 外设主均经 MMU；越权 → corex2 DBG_MSG 中 prp_*_mmu_err / c0_*_mmu_expt / c1_*_mmu_expt
  • 出错 ID：PRP_MMU_ERR_RID / PRP_MMU_ERR_WID（exception_analyze 打印）

每核 EMU / ETM（q32DSP）

基址: 0x1EEF000（csfr_base=0x1EE0000 + map_adr / 固定偏移，见 csfr.h）

每核一份：q32DSP(0/1) 基址 0x1EEF000 / +0x200。关键：EMU_CON/MSG、SSP/USP 限界、ETM_CON/PC0..3、WP0_*、ICFG/IPND/ILAT。

EMU_MSG 位（emu_msg[]，BIT(i) ↔ 名[31-i]）

位域名称说明

/* 使能栈溢出检测后命中 → EMU_MSG.BIT(3) stackoverflow */
q32DSP(id)->EMU_SSP_L = lo;  q32DSP(id)->EMU_SSP_H = hi;
q32DSP(id)->EMU_CON |= BIT(3);
