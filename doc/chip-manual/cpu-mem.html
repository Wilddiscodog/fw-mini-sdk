CPU 与存储系统

双核、映射、JL_SDR 寄存器与 isd/API 用法；Cache/MMU 见专页

双核 pi32v2

两颗 pi32v2 32bit DSP 核。每核独立 ETM/EMU；corex2 管总线/MMU 异常（见 Cache/MMU）。

CPU0（习惯主核）CPU1（习惯从核）
日常app_core / sys_event / 多数 UI·业务；BT 常 #C0btctrler/#C0btstack算力扩展；SOFT4 软中断常挂此核；未钉核任务（含多数音频）可被调度过来
绑核任务名 "#C0xxx" / irq_info 第三列=0"#C1xxx" / irq_info 第三列=1
音频任务/EQ/AEC 与双核协作细节 → audio.html。
/* debug.c: 每核栈溢出检测 */
q32DSP(0)->EMU_SSP_L = (int)cpu0_sstack_begin;
q32DSP(0)->EMU_SSP_H = (int)cpu0_sstack_end;
q32DSP(0)->EMU_CON |= BIT(3);

SDRAM 控制器（JL_SDR）

基址: 0x40400(段基址 + (64×grp + adr)×4, 见 WL82.h)

HSB 段控制器 JL_SDR（WL82.h JL_SDR_TypeDef）：CON0~CON13 时序/模式 + DBG_* 调试窗口。颗粒参数与时钟由 uboot + isd_config 上电配置，应用一般只改频率 API，不直接改 CON 时序。可选外挂 JL_PSRAM（0x40500）。

偏移寄存器属性说明
0x00CON0RW总控；BIT11=时钟通路使能（见位域）
0x04CON1WO时序/模式（WO，uboot 写）
0x08CON2RW刷新/行列相关
0x0CCON3RW模式寄存器扩展
0x10CON4RW延时/相位相关
0x14CON5RWDQ 延时等
0x18CON6RW保留/时序
0x1CCON7RW保留/时序
0x20CON8RW保留/时序
0x24CON9RW保留/时序
0x28CON10RW保留/时序
0x2CCON11RW保留/时序
0x30CON12RW保留/时序
0x34CON13RW保留/时序
0x38DBG_INFORW调试状态；异常 dmc_pnd 时打印
0x3CDBG_STARTRW调试监视起始地址
0x40DBG_ENDRW调试监视结束地址
0x44DBG_ADRRW触发地址锁存

位域 — SDR.CON0

位域名称说明
11CLK_ENSDRAM 时钟通路使能；clk_early_init 据此判定 sdram_clk 非 0（ota-loader clock.c）

DBG_INFO 已知位

位域名称说明

CON1~CON13 细位未在公开头文件给出；以 isd 键 SDRAM_MODE/CL/DQ_DLY 等交 uboot 配置为准。

SDRAM 烧录与时钟

isd 键作用常用
ENABLE_SDRAM0=无 SDRAM（须 CONFIG_SFC_ENABLE）1
SDRAM_SIZE容量2M / 8M
SDRAM_MODE0=SDR / 1=DDR / 2=DDR20
SDRAM_REFRESH_TIME/CYCLES刷新周期32 / 4K|8K
SDRAM_COLUM列地址位数相关0（A0-9）
SDRAM_PLL3_EN1：用 PLL3，SYS 须 240M，可开 USB2.01
SDRAM_PLL3_NOUSB_ENPLL3 跟 CL，禁用 USB2.00
SDRAM_CL非 PLL3 时的 SDRAM 钟档 0=120M…3=240M…11=288M3
SDRAM_DQ_DLY_TRMDQ 延时档（约对应钟速）5≈240M
SDRAM_WLCNT / D_DLY / RLCNT启动延时 / 上电测试 / 分频见 isd 注释

时钟推算（ota-loader clock.c）：若 JL_SDR->CON0 & BIT(11)，则 USB PLL3 8phase → sdram_clk = pll3_mhz/2；否则 4phase → pll2_clk/2。运行时改频：sdram_clock_set / system_sdram_clock_set（范围约 96M~244M，见 时钟章）。

/* 读 SDRAM 钟 */
u32 sdr = clk_get("sdram");
/* 与 SYS 一起改 */
system_sdram_clock_set(SYS_CLK_240M, 240000000);
/* 仅改 SDRAM */
sdram_clock_set(192000000);
/* 恢复 uboot 初值 */
system_clock_set_default();

链接、寻址与调试用法

  • 链接：sdk_ld_sdram.c 中 sdram(rwx): ORIGIN=0x4000120, LENGTH=SDRAM_SIZE；HEAP_END ≈ 0x4000120+SIZE-32
  • ENTRY：SDRAM 模式 0x4000120；SFC/无 SDRAM 模式见 isd ENTRY
  • CPU 视图：应用缓冲常用 0x4000000+ 偏移宏；可缓存别名与 NO_CACHE_ADDR 见 Cache 章
  • 异常 dmc_pnd（DBG_MSG bit14）：debug.c 打印 DBG_INFO / DBG_ADR / DBG_START / DBG_END
  • 使能监视示例：JL_SDR->DBG_INFO |= BIT(11);（配 DBG_START/END）
  • CONFIG_NO_SDRAM_ENABLE：无外挂颗粒，须同时 CONFIG_SFC_ENABLE；WiFi 等大缓冲场景一般不可关
改 SDRAM 钟后须保证颗粒与 DQ 延时仍匹配；超频/降频优先走 API，避免手改 CON 时序导致间歇性 bus fault。

链接与可搬移段

  • 链接脚本: cpu/wl82/sdk_ld_sdram.c / sdk_ld_sfc.c / sdk.ld
  • FREE_DACHE_WAY / FREE_IACHE_WAY (≤7) → CACHE_RAM_SIZE；cache_ram 起点 = 0x1F20000 + (8-FREE_IACHE_WAY)×4K
  • CONFIG_MMU_ENABLE 时 RAM0 前部留每核 0x2000 TLB（共 16KB）
  • movable / LTO: .movable.slot / stub 把热代码搬到 RAM 执行
