音频系统

LADC/PLNK/IIS 采集 → SRC/EQ/ANC → DAC, audio_server 框架与 AEC 回采

音频子系统框图

音频走 server 框架(liba/audio_server.a): 应用以 union audio_req 向 audio_server 发 ENC/DEC 请求; 采集源 mic/linein/plnk/iis/spdif, 播放走 DAC。AEC 回采=编码请求 aec_enable=1 + aec_s_attr(server/audio_dev.h), 回采通道 BIT(CONFIG_AEC_ADC_CHANNEL)。

MIC 录音与 AEC

req.enc.cmd = AUDIO_ENC_OPEN;
req.enc.sample_source = "mic";  req.enc.format = "pcm";
req.enc.sample_rate = 16000;    req.enc.channel = 1;
req.enc.channel_bit_map = BIT(1);            /* 通话 MIC 通道 */
/* AEC(参考 demo_edr/bt_decode.c): */
struct aec_s_attr a = {0};
a.EnableBit = AEC_EN|NLP_EN|ANS_EN;          /* AEC+NLP+ANS */
a.wideband = 1;  a.hw_delay_offset = 50;     /* 16k 宽带 */
req.enc.aec_attr = &a;  req.enc.aec_enable = 1;
req.enc.channel_bit_map |= BIT(CONFIG_AEC_ADC_CHANNEL);  /* 回采通道 */
【实测】AEC 依赖链: audio_server.a + libaec.a + libdns.a + libjlsp.a + 源码 jl_math(flrfft/flrifft)。VAD 也走 enc(use_vad 字段)。
