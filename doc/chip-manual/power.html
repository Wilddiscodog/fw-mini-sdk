电源管理

域、P33、WDT、充电

电源域

CORE DVDD / IO VDDIO / DCDC14 / 模拟域；档位 isd_config 烧录。P33 常电域：软关机与唤醒。相关：JL_POWER / JL_P33 / LRCT。

基址: 0x10000(段基址 + (64×grp + adr)×4, 见 WL82.h)

偏移寄存器属性说明
0x00CONRW电源控制（位域未公开，经 power_* API）

P33 / 关键

偏移寄存器属性说明
0x00PMU_CONRW
0x04RTC_CONRW
0x08SPI_CONRW
0x0CSPI_DATRW
POWER/P33 寄存器位域未在 SDK 头文件公开，请以驱动 API / ioctl 为准。

else
