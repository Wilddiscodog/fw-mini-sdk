电源管理

电源域、P33 软关机、充电、RTC(LRCT)、看门狗

电源域: CORE(DVDD 1.2V 档)/IO(VDDIO 档)/DCDC14/模拟域, 档位由 isd_config 烧录(VDDIO=4→3.2V 等); P33 常供电域支持软关机与唤醒。

P33 与软关机

/* asm/power_interface.h【实测: net_update 复位路径】 */
if (get_power_keep_state() & POWER_KEEP_RTC)
    power_set_soft_poweroff(10);   /* 软关机 10ms 后上电唤醒(RTC 保时场景) */
else
    system_reset();                /* 普通复位 */

充电与电池

  • charge.h: 充电电流/电压阈值平台数据(锂电池直充方案)
  • LRCT(0x13600 区, IRQ 44): RTC 计数与闹钟, 掉电域保持
  • LVD 低压检测、VCM/VDD 档位调试接口(p33.h)

看门狗

#include "asm/wdt.h"
wdt_close();            /* 关闭(调试) */
__wdt_clear();          /* 清狗(异常路径必须调, cpu/wl82/debug.c) */
