## 2. LCD 引脚表 (原理图最终结论)

| 信号 | 芯片引脚 | 复用名(原理图原文) | 管理方 |
|---|---|---|---|
| LCD_D0~D7 | PC1~PC8 | `PCx/LCD_Dx` | EMI 控制器(硬件), `dev_open("emi")` 自动配置 |
| LCD_WR | PC10 | `PC10/PWM3/RX2/LCD_WR/ADC9` | EMI 控制器(硬件) |
| LCD_CS | PC9 | `PC9/ADC8/TX2/LCD_CS/ADC8` | EMI 控制器(硬件) → `cs_pin=-1` |
| LCD_RS | PB5 | `PB5/SD_D0` | GPIO 软件(`lcd_rs_pinstate`) |
| LCD_RD | PB6 | `PB6_Wu/TX2/SD_CMD/ADC4` | GPIO 软件拉高(芯片无 LCD_RD 复用) |
| LCD_RESET | PB7 | `PB7/RX2/SD_CLK/ADC5` | GPIO 软件(`lcd_rst_pinstate`) |
| LCD_TE | PC0 | `PC0_Wu/ADC6/USB_DET` | GPIO 输入(撕裂同步) |
| 背光 LED_PWM | **PA6** | `PA6/RXA/CIS_D6` | GPIO 使能(网络名带 PWM, 可改 PWM 调光) |

**关键纠错(V0.7.0 遗留)**: 原 `rs_pin=PC9 / bl_pin=PB8` 是照搬原厂 DevKitBoard 的
默认值。本板 PC9 是 EMI 硬件 CS(原理图网络 LCD_CS), RS 实际在 PB5; 背光 PB8 错,
实为 PA6。已全部改为本板实测值。

**PB6(RD) 处理**: AC7912 的 LCD 复用脚只到 D0~D7/WR/CS, 没有 RD —— EMI 接口
只写。8080 面板的 RD 悬空可能引入误读, `JD9853_io_init()` 里 `gpio_direction_output(PB6, 1)` 拉高锁定。

## 3. 触摸引脚表 (与 V0.7.0 一致, 原理图再次确认)

| 信号 | 芯片引脚 | 说明 |
|---|---|---|
| I2C-CLK | PH0 | `iic0` 硬件 I2C |
| I2C-SDA | PH1 | 同上 |
| TP_INT | PH3 | GPIO(当前 20ms 轮询, 未用中断) |
| TP_RST | PH4 | GPIO 复位时序 |

触摸芯片 CST816 (id 0xB6, 7bit 地址 0x15)。

| 文件 | 修改 |

## 5. 上板验证要点 (MINI_LCD_SUPPORT=1)

1. 开机日志顺序: `[cst816] id 0xB6` → `LCD find JD9853` → `[lcd] LCD_JD9853 init_start`
   → `[lcd] LCD_JD9853 config succes` → 彩条 8 色循环(无 LVGL 时)。
2. 黑屏但日志正常 → 查背光(PA6)与 RESET(PB7) 时序; 屏色反 → 增删 `0x21`;
   色偏/发暗 → 替换 `jd9853_tuning` 调优段(见文件头说明)。
3. 触摸: 按 `[cst816]` 日志确认坐标方向, 需要时在 `cst816_read_point` 做旋转映射。
4. PA6 若需调光: 原理图网络名 LED_PWM, 可接 PWM 通道输出(占空比调亮度), 当前先 GPIO 全亮。
