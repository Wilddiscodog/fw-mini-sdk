## 平衡球规则 (当前)

- 开局 **30s**
- 苹果: +1 分(不加时)
- 香蕉: +2 分 **+5s**
- 西瓜: +5 分
- 炸弹: -3 分 **-10s**
- 控制: 绝对水平为零点(ax/ay≈0g)

## Flash 预留区 (isd)

`[RESERVED_CONFIG]` 内须包含(顺序敏感):

```
VM / BTIF / REC(4M) / PRCT
```

`REC` **必须**放在 `[RESERVED_CONFIG]`, 不可放 `[RESERVED_EXPAND_CONFIG]`。  
否则打包虽有 `REC_RESERVED` 空间, 运行时 `head_addr_get("REC")` 扫不到 → 聊天气泡空白。

- `VM_OPT=1`: 下载/OTA 尽量保留 WiFi 等 VM 数据
- 改预留布局后 USB 整烧可能重建目录导致 WiFi 丢失, 属预期; 布局稳定后日常用 OTA

## 烧录 / OTA

| 文件 | 用途 |
|---|---|
| `cpu/wl82/tools/jl_isd.fw` | USB 整机烧录(含布局/uboot) |
| `cpu/wl82/tools/update-ota.ufw` | 双备份网页/U盘 OTA(只换应用区) |
| `cpu/wl82/tools/jl_isd.ufw` | 整包 UFW |

改 `RESET` / `REC_*` / 预留表 → 建议 USB 烧 `jl_isd.fw`。  
仅改应用逻辑 → OTA `update-ota.ufw` 即可。
